1⚖️ 必ず守る法律 (これを破ると訴訟リスク)

⚠️ 特定電子メール法 (2002年制定)
広告・宣伝メールには オプトイン (事前同意) が原則必須。
例外: 「取引関係がある」「名刺交換した」「公開されている事業者メアド」のみオプトアウト方式可。

必須項目 (これがないと違法)

  • ✅ 件名に 「未承諾広告※」 表記 (※マーク必須)
  • ✅ 本文に 送信者名・住所 (個人事業主名・所在地)
  • ✅ 受信拒否の連絡先 (配信停止リンクまたは送信元アドレス)
  • ✅ 受信拒否者には 二度と送信しない (記録必須)

4🤖 Phase 2: メール文章 AI 生成

Claude API でカスタマイズ (Python例)

import anthropic

client = anthropic.Anthropic(api_key="...")

def generate_email(shop_name, area, category):
    prompt = f"""
    以下の飲食店向けに、シフト管理 SaaS RAKURAKU の営業メールを書いてください。

    店舗名: {shop_name}
    エリア: {area}
    業態: {category}

    トーン:
    - 「営業」感を消す
    - 同じ飲食業界の経営者として共感
    - 「家族との時間を取り戻したい」想いを伝える
    - 30 分のお時間と無料体験を提案

    必須含有事項:
    - 件名に「未承諾広告※」表記
    - 配信停止リンク (https://rakuraku-shift.com/unsubscribe?email=...)
    - 個人事業主名・所在地
    """
    response = client.messages.create(
        model="claude-3-5-sonnet-20241022",
        max_tokens=1500,
        messages=[{"role": "user", "content": prompt}]
    )
    return response.content[0].text

10🚫 絶対やってはいけない 10 のこと

  1. 食べログ・ホットペッパーから情報スクレイピング → TOS違反・訴訟リスク
  2. お問い合わせフォーム自動送信 → スパム認定・ブラックリスト入り
  3. 「未承諾広告※」表記なしメール → 特電法違反 (罰金100万円)
  4. 配信停止希望者への再送 → 同上
  5. 大量一斉送信 (1時間100件超) → ドメイン全体ブラックリスト入り
  6. CAPTCHA回避ツール使用 → 不正アクセス禁止法該当
  7. SNS DM 自動送信ツール使用 → 各プラットフォーム凍結
  8. 事実と異なる誇大表現 (「業界 No.1」「100% 成功」) → 景品表示法違反
  9. 競合の名指し批判 → 営業妨害・名誉毀損
  10. 取得した個人情報を別目的に利用 → 個人情報保護法違反
