📤 データをエクスポート

全データを JSON ファイルとしてダウンロード。Google Drive 等にバックアップしておくと安心です。

💡 推奨頻度: 月1回 (給与確定後) + 重要操作の前
📁 保存先例: Google Drive / iCloud / Dropbox / USB

📥 データをインポート

エクスポートした JSON ファイルから復元。機種変更・PC新調・障害復旧 に使用します。

📂
JSON ファイルをドラッグ or タップで選択
RAKURAKU でエクスポートしたファイルのみ対応

📋 取込内容プレビュー

⚠ 注意:
インポートすると現在のデータが 上書き されます。事前にエクスポートで現在のデータを保存しておくことを強く推奨します。

🗑 すべてのデータを削除

店舗を移転 / 廃業 / 完全リセット したい場合に使用。取り消しできません。

削除されるデータ: シフト・出退勤・スタッフ評価・売上記録・お知らせ・通知設定
削除されないデータ: サーバー側のアカウント情報 (Stripe課金等)
