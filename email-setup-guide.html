📧 メール通知 設定ガイド

問い合わせ・応募が来た瞬間に koizumishota0323@gmail.com へ自動でメールが届くようにする手順

🚀 Option A: Resend (推奨・5 分で完了)

Resend は 月 3,000 通まで完全無料。SMTP より高速で、設定が圧倒的に楽です。

手順

  1. resend.com でアカウント作成 (Gmail でログイン可)
  2. ダッシュボード → API Keys → Create API Key
  3. 権限: Sending access → Create
  4. 表示される re_xxxxxxxxxx をコピー (二度と表示されないので注意!)
  5. Railway ダッシュボードを開く: railway.app/dashboard
  6. RAKURAKU プロジェクト → Variables タブ
  7. 以下を追加: 
    RESEND_API_KEY=re_xxxxxxxxxx
EMAIL_USER=koizumishota0323@gmail.com
  8. Railway が自動再デプロイ (~2 分)
  9. 完了! 試しに 応募フォーム にダミー入力 → 自分にメールが届くか確認
✅ Resend の利点: SPAM 判定されにくい / 速い / 月 3,000 通まで無料 / ドメイン認証なしでも動く (Gmail 受信は OK)

📮 Option B: Gmail SMTP

Gmail のアプリパスワードを使う方法。Resend より複雑だが、無料枠は実質無制限。

手順

  1. Google アカウント設定: myaccount.google.com/security
  2. 2 段階認証を有効化 (これがないとアプリパスワード作れない)
  3. myaccount.google.com/apppasswords を開く
  4. アプリ名: RAKURAKU → 作成
  5. 表示される 16 文字の英数字をコピー (スペースは含めても OK)
  6. Railway Variables に追加: 
    EMAIL_USER=koizumishota0323@gmail.com
EMAIL_PASS=xxxxxxxxxxxxxxxx
SMTP_HOST=smtp.gmail.com
SMTP_PORT=465
  7. Railway 自動再デプロイ → 完了
⚠️ Gmail SMTP の注意点: 大量送信で BAN リスクあり (1 日 500 通推奨) / アプリパスワードは Google アカウントの 2 段階認証必須

🔔 (上級) スマホへの Push 通知

メールだけでなく、スマホに 即時 Push 通知 が欲しい場合は LINE Messaging API を使うのが最も簡単。

  1. LINE Developers でアカウント作成 → Messaging API チャネル作成
  2. チャネルアクセストークン (長期) を発行 → コピー
  3. Railway Variables に追加: 
    LINE_CHANNEL_TOKEN=xxxxxxxxxx
LINE_USER_ID=Uxxxxxxxxxxxxxx
