LINE 公式アカウント通知

β 版・設定可

LINE 公式アカウント (Messaging API) 経由でスタッフのLINEへ直接通知。開封率はメールの3倍以上。

⚪ LINE公式アカウント 未接続
📋 接続手順:
  1. LINE Developers Console で Messaging API チャネルを作成
  2. 「Messaging API設定」タブから Channel Access Token (長期) を発行
  3. 下のフォームに Channel ID + Channel Secret + Access Token を入力
  4. 「接続テスト」ボタンで疎通確認
  5. スタッフが 友だち追加 すると user_id が紐付け可能に
QR
(接続後)
接続後、ここに スタッフ向け友だち追加QR が表示されます。
スタッフがLINEで友だち追加 → 名前を送信 → 自動で user_id 紐付け → シフト通知が届くようになります。
🔔

プッシュ通知 (PWA)

β 版

RAKURAKU をホーム画面に追加するとブラウザ経由でプッシュ通知を受信できます。インストール不要。

⚪ プッシュ通知 未有効
💡 仕組み: Service Worker (sw.js) が常駐し、サーバーからの push を受信。
シフト確定・緊急依頼・締切が アプリ未起動でも届きます。
対応OS: iOS 16.4+ / Android Chrome / デスクトップ全般
