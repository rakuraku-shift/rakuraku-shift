📡 API ドキュメント

REST API v1 — 開発者向けリファレンス

ホーム > 連携 > API

🚀 はじめに

RAKURAKU API は REST 形式で、JSON を使用します。本番環境とテスト環境の 2 つがあります。

環境Base URL
本番https://api.rakuraku-shift.com/v1
テスト (Sandbox)https://api-sandbox.rakuraku-shift.com/v1

🔐 認証

API キーを Authorization ヘッダーで送信します。

Authorization: Bearer YOUR_API_KEY

API キーは「マイページ → 設定 → API キー」から発行できます。

⚠️ API キーは機密情報です。GitHub 等のパブリックリポジトリには絶対にコミットしないでください。

📋 シフト

GET/shifts

シフト一覧を取得

クエリパラメータ:

  • store_id: 店舗 ID (任意)
  • date_from: 開始日 YYYY-MM-DD
  • date_to: 終了日 YYYY-MM-DD
curl -H "Authorization: Bearer $TOKEN" \
  "https://api.rakuraku-shift.com/v1/shifts?date_from=2026-06-01&date_to=2026-06-30"
POST/shifts

新規シフトを作成

{
  "store_id": "st_xxx",
  "staff_id": "sf_xxx",
  "date": "2026-06-15",
  "start_at": "18:00",
  "end_at": "23:00"
}
PUT/shifts/:id

シフトを更新

DELETE/shifts/:id

シフトを削除

🪝 Webhook

以下のイベントを Webhook で受け取れます:

  • shift.created — シフト作成
  • shift.confirmed — シフト確定
  • timecard.clocked_in — 出勤打刻
  • timecard.clocked_out — 退勤打刻
  • labor_alert — 労基法アラート

Webhook URL は「マイページ → 設定 → Webhook」から登録できます。署名検証 (HMAC-SHA256) に対応。

📊 レート制限

プラン制限
月額プラン1,000 req/h
年額プラン5,000 req/h
Enterprise無制限 (要問合せ)

制限超過時は 429 Too Many Requests を返します。Retry-After ヘッダーをご確認ください。
