📊 営業リード管理ダッシュボード

RAKURAKU 社内専用 / 全データ localStorage に保存 (端末ローカル)
⚠️ 使い方: このダッシュボードは localStorage で動作 (サーバー非依存)。データはこの端末のみに保存されます。
バックアップは定期的に「CSV エクスポート」してください。 / 配信停止リストは別管理 (server.js の API or テキストファイル)。
店舗名業態エリアメアド電話URL ステータス送信日返信日メモ操作

📥 一括インポート (CSV/TSV)

フォーマット: 店舗名 [TAB] 業態 [TAB] エリア [TAB] メアド [TAB] 電話 [TAB] URL

📖 使い方ヘルプ
1. リード追加
「➕ リード追加」で空行追加。各セルをクリックして編集。

2. 一括インポート
Google Sheets からコピーした TSV/CSV をテキストエリアに貼って「インポート実行」。

3. ステータス管理
新規 → 送信済 → 開封済 → 返信あり → アポ獲得 → 成約 の順で更新。

4. メールテンプレ生成
フィルター済みのリードに対して、業態別カスタマイズされたメール本文を一括生成 (クリップボードへコピー)。

5. データバックアップ
「📥 CSV エクスポート」を毎週実行することを推奨。端末の localStorage は消えると元に戻りません。
