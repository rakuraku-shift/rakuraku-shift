価格上昇率

1注文ごとにベース価格の何%上昇するか。高いほど価格が激しく動く。

1% (おだやか) 8% 20% (激しい)
ベース¥500 → 1注文で → ¥540

ライバルペナルティ

ライバル商品が1注文されるごとに価格が下がる率。高いほどシーソー効果が強い。

1% (弱い) 5% 15% (強い)
ハイボール1注文 → ビールが -¥30 下落

価格計算ウィンドウ

何分以内の注文を価格計算に使うか。短いほど価格変動がリアルタイムに。

1分 5分 30分
直近 5分 の注文のみ反映。古い注文は自動で効果消滅。

価格変動しきい値

¥5 ¥10 ¥100

🌐 ローカルネットワーク設定ガイド

バーのWi-Fiに接続したスマホからアクセスできるようにする手順です。

① Node.jsをインストール後、ターミナルで:
cd ~/bar-exchange && npm install && npm start

② Macのローカルネットワーク IPを確認:
ipconfig getifaddr en0

③ 上のURLを http://[IPアドレス]:3000/customer.html に変更してQR生成
例: http://192.168.1.5:3000/customer.html
💡 同じWi-Fiに接続していればお客様のスマホからもアクセスできます
