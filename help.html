🚀 導入・開始
30 日 Pro 体験 (クレカ不要)はどうやって始めればいいですか？
トップページの「🎁 30日 Pro 体験で試す」ボタンから、店舗名・お名前・メールアドレスを入力するだけで開始できます。クレジットカードの登録は不要です。
アプリのインストールは必要ですか？
不要です。スマホ・PCのブラウザで利用できます。
iPhoneの場合は Safari で開いて「ホーム画面に追加」、Android Chromeは「アプリをインストール」でアプリのように使えます（PWA対応）。
スタッフ側の登録は必要ですか？
アカウント作成は不要です。店長が共有するQRコードをスタッフが読み取って、名前と希望日時を入力するだけで提出完了します。
何人くらいのスタッフを管理できますか？
スタッフ数は無制限です。月額料金は店舗単位なので、何人スタッフが居ても追加料金はかかりません。
3分で始めるガイドはありますか？
はい、こちらのガイドで、ステップ・バイ・ステップで案内しています。
⚙️ 使い方
QRコードはどこから発行できますか？
ご契約完了後、登録メールアドレスに 店舗専用URL と QRコード画像 が自動送信されます。
その後はサポート (koizumishota0323@gmail.com) までお問い合わせください。
  • ⬇️ PNG ダウンロード — 高画質画像
  • 🖨️ A4印刷 — 店内掲示用デザイン
  • 📲 LINE で共有 — テキストとURLをコピー
複数店舗の管理はできますか？
はい、店舗ごとに別URLが発行されるので、データを混在させずに複数店舗を運用できます。複数契約の場合はお問い合わせください、特別プランをご案内します。各店舗で月額がかかります。
深夜割増以外の割増賃金にも対応していますか？
現在は深夜（22:00〜翌5:00 +25%）の自動計算に対応しています。時間外労働・休日労働の割増は労基法に基づき別途計算が必要ですが、アプリ内に解説パネルを用意しています。
不足コマが出た時はどうなりますか？
3段階で自動的に募集をかけます：
  1. 既に提出しているスタッフへ「時間調整」依頼メールを一斉送信
  2. 自社スタッフに「時給アップで来てくれない？」と内部募集（時給インセンティブ付き）
  3. それでも足りなければ Timee / シェアフル / バイトル へワンタップで求人配信
Chrome拡張機能は必須ですか？
必須ではありません。拡張機能なしでも「クリップボード自動コピー → 各サイトを新タブで開く → ペースト」の半自動配信が動作します。
拡張機能を入れると、フォームに自動入力されるため完全ワンタップになります。インストール手順
💴 料金・解約
月額料金はいくらですか？
1店舗あたり 月額 ¥4,990（税込）です。初期費用・契約期間の縛り・違約金は一切ありません。
年払いプランなら ¥49,900/年（2ヶ月分お得） もご用意しています。
解約はいつでもできますか？
はい、いつでも解約可能です。違約金は一切ありません。解約申請の翌月以降、ご請求は発生しません。
30 日 Pro 体験期間中に解約したらどうなりますか？
30 日 Pro 体験期間中はクレカ登録不要なので、何もせずに離脱すれば自動的に終了します。費用は一切発生しません。
支払い方法は何がありますか？
クレジットカード（Visa / Mastercard / JCB / AMEX）と銀行振込（請求書発行）に対応しています。クレジットカードは月次自動引落です。
領収書は発行できますか？
はい、Stripe（決済代行）から自動的に領収書PDFがメール送信されます。インボイス対応の登録番号も記載されます。
🆘 トラブルシューティング
ライセンスコードのメールが届きません
以下をご確認ください：
  1. 迷惑メールフォルダに振り分けられていないか
  2. 登録メールアドレスのスペルミスがないか
  3. 会社のメールセキュリティで自動ブロックされていないか（@gmail.comからの送信です）
それでも届かない場合は koizumishota0323@gmail.com までご連絡ください。
スタッフが提出しても店長画面に反映されない
以下をご確認ください：
  1. 店長とスタッフが 同じ店舗URL（?shop=◯◯）を使っているか
  2. 画面右下に 「● オンライン同期中」 が表示されているか（緑バッジ）
  3. 店長画面の ⌘+Shift+R で強制再読込
「オフライン」表示の場合、インターネット接続を確認してください。
管理者PINを忘れました
初期PINは 1234 です。変更後に忘れた場合は、ブラウザの設定でlocalStorageをクリアすると初期PINに戻ります。
※ ただしシフトデータも消えるため、データバックアップから復元するか、サポート (koizumishota0323@gmail.com) までご連絡ください。
QRコードを読み取っても画面が表示されない
QRコードに埋め込まれているURLが古い場合があります。サポート (koizumishota0323@gmail.com) までご連絡いただければ最新QRを再送します。
または、登録メールに記載のURLを直接ブラウザに貼り付けてアクセスをお試しください。
スマホで「位置情報が取得できません」と出る
スマホの設定 → ブラウザ → 位置情報サービスを 「許可」 に変更してください。
iPhone Safari: 設定 → Safari → 位置情報 → 「確認」または「許可」
Android Chrome: 設定 → サイトの設定 → 位置情報 → ブロックされたサイトに RAKURAKU があれば許可に変更
※ 位置情報がOFFでも打刻はできますが、店舗外打刻のアラートが店長に飛びます。
給与計算が間違っている気がする
給与計算は以下のルールで自動計算しています：
• 通常時給: マスタ管理で設定した時給 × 勤務時間
• 深夜割増: 22:00〜翌5:00 は時給×1.25倍 (労基法第37条準拠)
• 休憩控除: 6時間超で45分、8時間超で60分を自動控除
もし金額が違うと思われたら、出退勤打刻履歴と希望時間が一致しているかご確認ください。
解決しない場合は サポート までスクリーンショットをお送りください。
シフト提出した日時を後から変更したい
スタッフ自身がシフト提出画面で 同じ日時をもう一度提出 すると上書きされます。
シフト確定後の変更は「休み変更届」(マイシフト画面) から店長に申請してください。店長承認後に変更が反映されます。
複数の端末で同時に編集すると競合しますか？
Socket.io によるリアルタイム同期で、複数端末からの編集はすぐに全端末に反映されます。最後に書き込まれた内容が正となります (Last-Write-Wins)。
同じシフトを2人が同時に編集している場合、後から保存した方が優先されますので、店長同士で運用ルールを決めてご利用ください。
✨ 機能・カスタマイズ
給与計算の出力データは？
スタッフごとの月次給与（時給×勤務時間+深夜割増+交通費）をCSV/印刷可能形式で出力できます。深夜割増は労働基準法第37条準拠で自動計算されます。
スタッフ評価機能とは？
スタッフをポジションごと（ホール・キッチン・レジ等）に5段階で評価し、シフト編成時に 得意なポジションに自動配置 できる機能です。
店舗ロゴをカスタマイズできますか？
現在はベータ機能として、店舗管理画面の設定からロゴ画像をアップロードできます。今後のアップデートで本格対応予定です。
予約管理機能はありますか？
現バージョンではシフト管理に特化しています。予約管理は2026年下期に追加予定です。要望はぜひお寄せください。
🔒 セキュリティ・プライバシー
データはどこに保存されていますか？
日本国内のクラウドサーバー（Railway）で暗号化保管されています。スタッフの個人情報（メールアドレス等）は同サーバー内に閉じており、第三者への提供は行いません。
クレジットカード情報は安全ですか？
RAKURAKU はクレジットカード情報を保持していません。決済は Stripe（PCI DSS Level 1 準拠） が直接処理します。
解約後、データはどうなりますか？
契約終了後3ヶ月間データを保管し、その後完全に削除します。ご本人からの即時削除要請にも対応します。
管理者PINの強度は？
4桁PINで、5回連続失敗で運営に通知されます。
より強固な保護をご希望の場合は、ブラウザ自体のパスワードロック・指紋認証併用を推奨します。
👤 スタッフ向け (アルバイト・社員)
店舗から教わったURLにアクセスしたら何をすればいい?
3つのタブが表示されます:
① シフト提出 — 来月のシフト希望を出す
② アンケート — 月1で職場評価 (匿名)
③ シフト管理 — 店長専用 (タップしない)
最初は ① でお名前 + メール + 希望日時を入力するだけです。
確定したシフトはどこで確認できる?
スタッフ用 URL の 「📅 マイシフト」 リンク、または myshift.html から確認できます。
ホーム画面に「マイシフト」ショートカットを追加しておくと、出勤前に1タップで確認可能です。
急な体調不良で休みたい時はどうする?
マイシフト画面の 「🆘 休み変更届」 ボタンから提出してください。店長に通知が届き、承認/却下されます。
できるだけ早めに 提出をお願いします (代替スタッフの手配が必要なため)。
出退勤はどうやって打刻する?
マイシフト画面の 「⏰ 出退勤打刻」 から、店舗内で打刻してください。
GPS位置情報 で店舗にいることが確認されます。範囲外で打刻すると店長に警告が届きます。
休憩はどう取ればいい?
出勤打刻 → 休憩開始 → 休憩終了 → 退勤打刻 の流れで打刻します。
労基法により 6時間超の勤務は45分以上、8時間超は60分以上 の休憩が必須です。
給与明細はもらえる?
店舗の運用方針によりますが、店長が 月次の給与明細PDF を発行してメールでお送りすることができます。
もしまだ受け取ったことがない場合は、店長に「RAKURAKU の給与明細PDF をください」とお願いしてみてください。
日本語以外の言語に切り替えられる?
はい、画面右上の言語切替で 日本語 / English / 中文 / 한국어 に切り替えできます。
シフト希望提出・打刻・マイシフト確認 すべて母国語で操作できます。

業種は飲食店だけですか？
主に バー・飲食店 に最適化していますが、シフト制で運営されている業種（小売・美容・サービス）でも基本機能はお使いいただけます。深夜割増計算は飲食店業態向けに特化しています。
機能追加の要望は受け付けていますか？
はい、大歓迎です！ koizumishota0323@gmail.com までご連絡ください。ヒアリング協力店舗様のご要望を優先的に開発しています。
無料デモは受けられますか？
はい、15分のオンラインデモ (Zoom/Google Meet) を承っています。🎁 デモ予約フォーム から24時間以内に Zoom URL をお送りします。
ヒアリング実績はどれくらいありますか？
2026年3月のサービスローンチから順調に成長中で、現在は 120店舗超 のパートナー様にご利用いただいています (バー・居酒屋・カフェが中心)。ヒアリング協力店舗様には 最大2ヶ月無料 等の特典を提供しています (無料期間上限は2ヶ月)。お早めにご相談ください。
LINE公式アカウント連携はできますか?
はい、通知設定 ページから LINE Messaging API のチャネル情報を入力するだけで、シフト確定通知・お知らせを LINE 経由で全員に配信できます。
LINE 公式アカウントが既にある店舗様であれば、追加費用なしで連携可能です。
給与計算ソフト (freee/マネーフォワード) と連携できますか?
はい、給与明細画面から freee形式 / マネーフォワード形式 / 汎用CSV の3形式でエクスポートできます。
各給与計算ソフトの「CSV取込」機能でそのまま読込めるフォーマットなので、二重入力が不要になります。
紹介プログラムはありますか?
はい、🤝 紹介プログラム から他の店舗を紹介すると、紹介元・紹介先 両方が1ヶ月無料 になります。
紹介コード (RAKU-XXXX-YYYY) を発行 → 紹介先の店舗が登録時にコード入力 → 自動で適用されます。
無料期間はどこまで延長できますか? (紹介・パートナー・キャンペーン)
📌 RAKURAKU の無料期間ポリシー:
1店舗あたり 最大 2ヶ月まで を上限としています。

内訳の例:
  • 新規登録: 30日 Pro 体験トライアル (約半月)
  • 紹介プログラム: 紹介元 +1ヶ月 / 紹介先 +1ヶ月
  • パートナー店舗 (限定): 追加で +1ヶ月 (最大2ヶ月まで)
  • 季節キャンペーン: ケースによる (上限2ヶ月)
※ どんなに重なっても 2ヶ月を超える無料期間は提供しません。これは公平性と運営持続性のためのルールです。
