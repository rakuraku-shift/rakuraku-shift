🔧 Stripe セットアップ手順書 (社内専用)

CONFIDENTIAL 本ページは社内専用です。検索エンジンには公開していません。

📋 セットアップ全体像

  1. Stripe アカウント作成 (本人確認・税情報)
  2. Product (商品) 作成
  3. Price ID 発行 (月額 ¥4,990 / 年額 ¥49,900)
  4. Webhook 設定 (subscription.created / .updated / .deleted)
  5. 環境変数を Railway に登録
  6. テスト環境で決済 → 本番モード切替

1️⃣ Product 作成

Dashboard → 商品 → 商品を追加
  • 商品名: RAKURAKU シフト管理
  • 説明: 飲食店向けシフト管理 SaaS
  • 画像: icon-512.png をアップロード

2️⃣ Price ID 発行

月額プラン
  • 金額: 4990 JPY
  • 請求期間: 月次
  • 無料トライアル: 30 日間
  • Price ID をコピー → STRIPE_PRICE_ID_MONTHLY
年額プラン
  • 金額: 49900 JPY
  • 請求期間: 年次
  • 無料トライアル: 30 日間
  • Price ID をコピー → STRIPE_PRICE_ID_ANNUAL

💴 料金プラン (シンプル課金)

⚠️ 料金の流れ: ① 登録〜30日 = ¥0 (trial_period_days:30) → ② 31日目以降 = 通常 ¥4,990 / 月 (年額は ¥49,900 / 年)。
イントロ割引クーポンは廃止 (2026-06-11)。「30日無料トライアル → 通常料金」のシンプルな課金です。STRIPE_COUPON_INTRO は使用しません（環境変数も不要）。
テストモードで 4242 4242 4242 4242 登録 → Dashboard の顧客 → サブスクリプションで「トライアル30日 → 次回請求 ¥4,990」を必ず確認してから本番化。

3️⃣ Webhook 設定

Dashboard → Webhook → エンドポイントを追加
  • URL: https://rakuraku-shift.com/api/stripe/webhook
  • 監視イベント:
checkout.session.completed
customer.subscription.created
customer.subscription.updated
customer.subscription.deleted
invoice.payment_succeeded
invoice.payment_failed

Webhook 署名シークレットをコピー → STRIPE_WEBHOOK_SECRET

4️⃣ 環境変数

変数名値環境
STRIPE_SECRET_KEYsk_live_xxx本番
STRIPE_PUBLISHABLE_KEYpk_live_xxx本番
STRIPE_PRICE_ID_MONTHLYprice_xxx本番
STRIPE_PRICE_ID_ANNUALprice_xxx本番
STRIPE_WEBHOOK_SECRETwhsec_xxx本番
STRIPE_TEST_SECRET_KEYsk_test_xxxテスト

5️⃣ Railway へ登録

railway variables set STRIPE_SECRET_KEY=sk_live_xxx
railway variables set STRIPE_PRICE_ID_MONTHLY=price_xxx
railway variables set STRIPE_PRICE_ID_ANNUAL=price_xxx
railway variables set STRIPE_WEBHOOK_SECRET=whsec_xxx
railway up

6️⃣ テスト決済

テストカード番号
  • 成功: 4242 4242 4242 4242
  • 失敗: 4000 0000 0000 0002
  • 3D セキュア要求: 4000 0027 6000 3184
  • 有効期限・CVC: 任意の未来日付・任意 3 桁

7️⃣ 本番モード切替チェックリスト

  1. ✅ 本人確認 (運転免許 / マイナンバーカード)
  2. ✅ 銀行口座登録 (入金先)
  3. ✅ 特定商取引法表記の公開 (/legal/specified-commercial.html)
  4. ✅ プライバシーポリシー公開
  5. ✅ 利用規約公開
  6. ✅ Webhook の本番 URL 接続テスト
  7. ✅ 環境変数の本番キー切替確認
✅ 切替完了後: テスト決済で実際にカードを切り、Dashboard で入金記録が出ることを確認。問題なければサービス開始。
