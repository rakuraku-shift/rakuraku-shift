5❓ 想定質問 Q&A 10 選

Q1: 料金は?
A: 個人店なら永久無料 (Free Plan)。多店舗運営なら Pro ¥4,990/月 (1 店舗あたり) で全機能。20 店舗以上ならEnterprise で個別見積 (ボリュームディスカウント有り)。
Q2: 既存システム (Airシフト・Shiftee) からの移行は?
A: 移行サポート無料。スタッフデータ・過去シフト・打刻履歴を CSV で一括取込み。1 日で完了します。並行運用も可能。
Q3: セキュリティ・コンプライアンスは?
A: SSL/TLS 1.3 + bcrypt + AES-256。GDPR・個人情報保護法準拠。Stripe (PCI DSS Level 1) で決済処理。詳細は /security.html をご覧ください。Enterprise なら SSO (SAML/OAuth) 対応。
Q4: 現場 (店長) が反対しそうですが…
A: 逆に店長の負担激減します。シフト作成 5h → 1h、給与計算 8h → 1h。「LINE で個別連絡」が不要になり、無断欠勤も激減します (実績: 月 4 件 → 0 件)。
Q5: スタッフへの教育コストは?
A: 5 分でセットアップ完了。スマホで使えるので、ITが苦手なベテランスタッフでも問題なし。動画チュートリアル 32 本も用意 (/tutorials.html)。
Q6: API 連携・カスタマイズは?
A: REST API + Webhook 対応 (Pro 以上)。Zapier / freee / Slack / Google Calendar など 20+ サービスと連携可能。Enterprise なら個別 API 開発も承ります。
Q7: サポート体制は?
A: Free = LINE/メール対応 (営業時間内)、Pro = 24h 以内返信の優先サポート、Enterprise = 24/7 サポート + 専任カスタマーサクセス (月次定例ミーティング)。
Q8: 解約の縛り・違約金は?
A: 一切ありません。マイページから 1 クリックで解約可能。Pro プラン初回課金後 30 日以内なら全額返金保証もあります。
Q9: 御社の信頼性は? いつから?
A: 2026 年春サービス開始、現在 120 店舗超のヒアリング実績。代表 (小泉) 自身が飲食店関係者へのヒアリングを継続実施しており、業界の課題を熟知しています。
Q10: 競合と比べて何が違う?
A: 飲食店・夜営業特化が決定的に違います。Airシフトは大企業向け汎用、Shiftee は多業種、freee は給与計算が本業。RAKURAKU だけが個人店も多店舗チェーンもカバーする飲食特化 SaaS です。詳細比較は/competitor-matrix.html で 12 社徹底比較しています。
